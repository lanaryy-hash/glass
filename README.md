# Glass

A light, very customizable music player for **Windows 10/11** and **macOS 12+**.
Your Spotify, Apple Music, SoundCloud and YouTube libraries plus your own files, in one place — using about 30 MB of RAM and 0 % CPU when idle.

## Download

Get `Glass-windows.zip` or `Glass-mac.zip` from the [releases page](https://github.com/lanaryy-hash/glass/releases).
Installed copies update themselves: an **Update available** button appears in the title bar.

- **Windows:** unzip and run `Glass.exe`.
- **Mac:** unzip, drag Glass to Applications, then once in Terminal: `xattr -cr /Applications/Glass.app` (the app is not signed by Apple).
  Data lives in `~/Library/Application Support/Glass`.

## Where the sound comes from

| Source | Sound |
| --- | --- |
| Spotify tracks | The official Spotify Web Player, hidden inside Glass (real versions, Premium). Connect once in Settings > Playback: create an app on developer.spotify.com and tick *Web API* and *Web Playback SDK*. |
| Apple Music | The official music.apple.com player, hidden inside Glass (subscription needed for full songs). Without an account, paste a playlist or album link: the sound then comes from YouTube. |
| SoundCloud | Directly from SoundCloud (no account; Go+ tracks only give the 30 s preview). |
| YouTube / YouTube Music | Playlists, videos, albums and channels, through [yt-dlp](https://github.com/yt-dlp/yt-dlp) (installed automatically). |
| Your files | mp3, flac, m4a, wav, ogg… played directly. |

In **Auto** mode Glass uses the official player when it can and falls back to YouTube otherwise. **YouTube only** mode is lighter (no hidden web player) but can pick another version of a song.

## Features

- **Home** — shortcuts to your playlists, recently played songs, your artists (with photos) and your playlists.
- **Library** — pin, rename, change covers, duplicate; drag songs onto playlists; sort by any column.
- **Add a link** (+ button) — Spotify, Apple Music, SoundCloud or YouTube playlists, albums, songs and profiles.
- **Search** (Ctrl+F) — your lists plus the Spotify catalog (or Apple Music when Spotify is not connected), with artist pages.
- **Lyrics** (Ctrl+L) — synced lyrics from Spotify, then LRCLIB, then the shared [glass-lyrics](https://github.com/lanaryy-hash/glass-lyrics) database. A local AI (whisper.cpp) aligns lyrics to the actual audio and writes missing ones.
- **Mini player** (Ctrl+M) — blurred cover background, karaoke lyrics, mouse wheel for volume.
- **Themes** — 18 built-in themes (including Evangelion and Code Geass with real wallpapers), animated backgrounds and particles, neon glow, accent color from the cover. Save your own themes and share them as `.glasstheme` files.
- **Covers** — right-click a song or playlist > *Change cover*, with a search on [COV](https://covers.musichoarders.xyz).
- **Logo** — Settings > Logo: pick one of the Glass logos or your own image.
- **Discord** — "Listening to" status on your profile.
- **More** — crossfade, radio when a list ends, sleep timer, playback speed, queue, offline downloads, media keys, tray icon, start with Windows.

Shortcuts: Space, Ctrl+arrows, Ctrl+F, Ctrl+L, Ctrl+Q (queue), Ctrl+M (mini player). On Mac use Cmd.

## Performance

Glass only redraws when something changes: 0 % CPU when idle, about 30 MB of RAM (+ about 140 MB for the hidden Spotify web player when it is used). Animated backgrounds and particles cost about 3 % of one core while Glass is visible.

## Building from source

Windows: Visual Studio 2022+, CMake and Rust, then run `build.bat` (it builds the Rust engine and the app; the result is `build\Release\Glass.exe`).
Every push to `main` builds Windows and Mac versions with GitHub Actions and publishes a release.

Code layout: `main.cpp` (shared UI, playback, lyrics) · `win.cpp` (Windows) · `mac.mm` (Mac) · `platform.h` (glue) · `engine/` (Rust engine: Spotify library, lyrics, Web API).
The app icon is generated by `node assets/make_logo.js`.
